# EzNetwork — 汉语复杂网络构建分析平台

面向计算语言学研究的**中文文本复杂网络分析工具**（Windows 桌面程序）。

## 下载安装

前往 **[Releases](../../releases/latest)** 页面，下载最新的安装程序：

```
EzNetwork-Setup-<版本号>-<构建时间>-win-x64.exe
```

双击运行安装即可，无需另行配置 Python 环境 —— 运行所需的全部依赖（含中文分词模型与词向量工具链）已内置在安装包中。

> 文件名中的 `<构建时间>` 是构建时刻（如 `20260921-2022` 表示 2026-09-21 20:22），
> 用于区分同一版本号下的不同构建，按该时间选择最新的一份即可。

### 系统要求

- Windows 10 / 11（64 位）
- 建议 8 GB 及以上内存
- 安装包约 200 MB，安装后占用约 1.5 GB

## 功能

### 5 种网络类型（节点/边定义不同，指标统一）

| 网络 | 节点 | 边 | 方向 |
|------|------|-----|------|
| 语义相似度网络 | 词（2-4字） | 词向量相似度 ≥ 阈值 | 无向加权 |
| 构词网络 | 字 | 词内相邻字对 | 有向加权 |
| 词同现网络 | 词 | 滑动窗口内共现 | 无向加权 |
| 字同现网络 | 字 | 汉字滑窗共现 | 无向加权 |
| 依存句法网络 | 词 | 依存弧（中心词→依存词） | 有向加权 |

### 指标计算

- **宏观指标**：节点数/边数、密度、平均度、直径、平均路径长度、可达比例、聚类系数、度相关系数、随机网络对比（20 次采样均值±标准差）与小世界系数
- **中观指标**：Louvain 社区数、模块度、孤立节点数与 k-core 嵌套结构
- **微观指标**：度、加权度、度中心性、接近中心性、中介中心性、特征向量中心性、PageRank、局部聚类系数、核数
- **路径距离口径**：可选「无权路径」（每条边距离为 1）或「距离＝1／权重」（强联系距离更短），该选择统一作用于直径、平均路径、接近中心性、中介中心性、随机路径基线与小世界系数
- **有向分析（口径版本 3）**：构词与依存句法网络不为指标计算做无向投影；社区检测使用带权有向 Louvain 与有向模块度；全局聚类使用无权 Fagiolo 有向定义；随机对照使用有向 ER 网络
- **幂律检验**：对度分布做拟合与检验，输出拟合优度与似然比对比

### 其他能力

- 交互式网络可视化（缩放、拖拽、按指标着色、社区着色）
- 中英文界面切换
- 多语料批量分析，结果导出为 Excel
- 词向量模型可选（内置与自定义）
- 分词器可选（jieba / spaCy / pkuseg）
- 分析报告导出
- 机器学习：网络指标分类与特征重要性分析
